# Sistema de Tracking Legal

## Problema
Los clientes de servicios legales experimentan altos niveles de incertidumbre por la falta de visibilidad en el estado de sus trámites, lo que impacta en ansiedad para el cliente y un alto volumen de consultas constantes que saturan al abogado.

## Usuarios o interesados
Clientes finales, abogados, asistentes del estudio jurídico.

## Objetivo
Implementar un sistema de seguimiento digital mediante códigos estilo logística para proveer una hoja de ruta clara al cliente y enviar mensajes automatizados de progreso.

## Alcance inicial
Generación de códigos de seguimiento únicos, portal de consulta web del estado del proceso y módulo para envío de mensajes automatizados.

## Fuera de alcance
Pasarelas de pago para honorarios y gestión interna administrativa del estudio jurídico.
